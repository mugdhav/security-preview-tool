SQL Injection

CWE-89· Injection HIGH confidence ·api/reports.py:142

What's wrong

User-controlled owner is interpolated straight into the SQL string. An attacker can change ?user= to read or modify any row in reports. The AST check confirmed the argument is an f-string built from a request value — confidence HIGH.

Remediation
Vulnerable
cur.execute(f"SELECT * FROM reports WHERE owner = '{owner}'")
Secure — parameterised
cur.execute("SELECT * FROM reports WHERE owner = %s", (owner,))
